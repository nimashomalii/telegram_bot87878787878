# Telegram Crypto Bot (ccxt) — ربات تلگرام کریپتو

ربات تلگرام برای مشاهده صرافی‌ها، نمادها، قیمت، نمودار شمعی (Candlestick) و خروجی اکسل از داده‌های OHLCV با استفاده از ccxt. تمام پیام‌ها به زبان فارسی نمایش داده می‌شوند.

## امکانات
- پیام خوش‌آمدگویی فارسی و نمایش فهرست صرافی‌ها بر اساس حجم معاملات 24ساعته (تقریبی)
- دکمه‌های شیشه‌ای برای انتخاب صرافی و سپس نمادها با قیمت لحظه‌ای
- نمایش منوی نماد: «قیمت فعلی»، «رسم نمودار»، «دریافت اکسل»
- رسم نمودار شمعی با matplotlib و ارسال تصویر
- خروجی اکسل (OHLCV) با pandas + openpyxl
- «توضیحات» برای دریافت اطلاعات تکمیلی از CoinGecko

## ساختار پروژه
```
.
├── bot/
│   ├── main.py               # منطق اصلی ربات تلگرام
│   ├── exchange_utils.py     # توابع ccxt برای دریافت صرافی‌ها/نمادها/قیمت/OHLCV
│   ├── charting.py           # رسم نمودار شمعی و ذخیره به PNG
│   ├── excel_exporter.py     # خروجی اکسل برای داده‌های OHLCV
│   └── coin_info.py          # دریافت اطلاعات تکمیلی از CoinGecko
├── artifacts/                # خروجی‌های نمودار و اکسل (Auto-created)
├── requirements.txt          # وابستگی‌ها
├── run_on_colab.ipynb        # اجرای سریع در گوگل کولب
└── README.md                 # همین فایل
```

> نکته: اگر امکان ایجاد `.env.example` در مخزن شما محدود است، مقادیر محیطی را طبق بخش راه‌اندازی تنظیم کنید.

## راه‌اندازی محلی (Local)
1. ساخت محیط و نصب وابستگی‌ها:
```bash
python -m venv .venv
. .venv/bin/activate   # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

2. تنظیم متغیر محیطی توکن تلگرام:
```bash
export TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN   # ویندوز پاورشل: $env:TELEGRAM_BOT_TOKEN="..."
```

3. اجرا:
```bash
python bot/main.py
```

## دیپلوی روی سرور
- از همان مراحل نصب استفاده کنید.
- سرویس systemd بسازید یا از Docker/PM2/supervisor برای اجرای دائم استفاده کنید.

## استفاده در تلگرام
- `/start` را ارسال کنید.
- از فهرست صرافی‌ها یکی را انتخاب کنید.
- سپس نماد/جفت‌ارز را انتخاب کنید.
- برای نماد انتخاب شده:
  - «قیمت فعلی»: نمایش قیمت و زمان محلی
  - «رسم نمودار»: تعداد کندل + تایم‌فریم را وارد کنید و تصویر دریافت کنید
  - «دریافت اکسل»: تایم‌فریم و بازه زمانی را وارد کنید و فایل Excel بگیرید
  - هر زمان «توضیحات» را تایپ کنید تا اطلاعات کلی از CoinGecko نمایش داده شود

## نکات فنی و ملاحظات تولیدی (Production)
- ccxt از APIهای عمومی استفاده می‌کند و محدودیت نرخ (Rate Limit) دارد؛ در کد از `enableRateLimit` و زمان‌بندی معقول استفاده شده است.
- محاسبه حجم 24ساعته برای هر صرافی به صورت تقریبی انجام می‌شود (جمع `quoteVolume` برای نمادهای با کوئوت USD/USDT/USDC/BUSD/TUSD).
- برخی صرافی‌ها ممکن است برخی متدها را پشتیبانی نکنند یا داده‌ها ناقص باشند؛ خطاها مدیریت شده‌اند.
- خروجی‌ها در پوشه `artifacts/` ذخیره می‌شوند.
